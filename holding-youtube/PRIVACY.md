# Privacy Policy — Holding YouTube

Last updated: 13 October 2026

Holding YouTube is a personal tool operated by its owner for the owner's own YouTube channel. It has no
other users.

**Data accessed.** With the owner's Google OAuth consent, the tool uses the YouTube Data API and the
YouTube Analytics API to upload, update, schedule and delete the owner's own videos, set their thumbnails,
post comments as the owner's channel, and read the owner's channel reports.

**Storage.** OAuth tokens and report data are stored only on the owner's computer. Nothing is sold, shared
with third parties, or used for advertising. No data of other YouTube users is collected.

**Google API Services.** The tool's use of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements, and to the
[YouTube API Services Terms of Service](https://www.youtube.com/t/terms). Google's privacy policy:
https://policies.google.com/privacy

**Revoking access.** Access can be revoked at any time at https://myaccount.google.com/permissions ;
the owner can also delete the locally stored tokens.

**Contact.** Through the owner's GitHub profile: https://github.com/ahmet35yildiz
